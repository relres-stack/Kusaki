ДОРОГА К РАССВЕТУ - ландшафт и блокаут по референсу
====================================================

Что здесь лежит (папка ForImport/RoadToDawn)
  RoadToDawn_heightmap_2017.png   карта высот, 16 бит, 2017 x 2017, 1 вершина = 1 м, диапазон -22 .. +98 м
  rtd_layout.json                 раскладка: дорога, улицы, заборы, ворота, башни, дома, река, деревья, старт Реднека
  rtd_build_level.py              скрипт для Unreal (Python Editor Script), расставляет всё из rtd_layout.json
  rtd_generate_terrain.py         генератор (Python + numpy/scipy/opencv), если захочется поменять размеры или высоты
  plan_preview.jpg                план сверху (север вверху)
  overlay_on_reference.jpg        план, наложенный на референс (для сверки)
  mask_road / rock / meadow / riverbank.png   маски слоёв Landscape, те же 2017 x 2017, пока не подключены

Масштаб (взят по референсу, кольцо 500 м как договорились)
  внешний забор: окружность, радиус 250 м, центр = начало координат
  внутренняя стена: радиус 168 м, центр сдвинут на 20 м восточнее и 60 м севернее (как на референсе, стены сходятся сзади)
  кольцевая дорога между стенами, радиус 207 м
  внешние ворота: (0, -250), внутренние: (0, -107)    [x = восток, y = север, метры]
  дорога от внешних ворот до скалы: 1030 м, серпантин с тремя коленами, средний уклон 5 %, максимум 6.8 %
  скала Реднека: (-300, -842), высота +61 м над воротами, по прямой до ворот 664 м
  река: к востоку, около x = 320 м, течёт с севера на юг
  холм с комплексом (бетонное здание): северо-запад, (-212, +126)

Соответствие координатам Unreal (важно)
  UE X = север * 100 см,  UE Y = восток * 100 см,  UE Z = высота * 100 см
  то есть ворота внешние: X = -25000, Y = 0;  старт Реднека: X = -84200, Y = -30000, Z = около 6100

ШАГИ
----
1. Новый уровень
   File > New Level > Empty Level. Сохраните как Content/RoadToDawn/Lvl_RoadToDawn_Terrain.
   Старый уровень Lvl_RoadToDawn_Blockout не трогаем.

2. Landscape
   Режим Landscape (Shift+2) > вкладка New Landscape > Import from File.
     Heightmap File:   ForImport/RoadToDawn/RoadToDawn_heightmap_2017.png
     Heightmap Resolution:  2017 x 2017  (выберите в списке; если нет, значит файл не прочитан как 16 бит)
     Location:   X = 0   Y = 0   Z = 0   (при импорте это ЦЕНТР ландшафта; после импорта в Details актор покажет Location -100800, -100800, 0 - так и должно быть)
     Rotation:   0, 0, 0
     Scale:      X = 100   Y = 100   Z = 100
     Section Size: 63 x 63 Quads,  Sections Per Component: 1 x 1   (получится 32 x 32 компонента)
     Landscape Material: /Game/RoadToDawn/Materials/M_RTD_Terrain
   Нажмите Import.
   Ландшафт должен быть ровно 2016 м, центр в начале координат.

3. Python
   Edit > Plugins, найдите "Python Editor Script Plugin", включите, перезапустите редактор (если ещё не включён).

4. Расстановка
   File > Execute Python Script... > ForImport/RoadToDawn/rtd_build_level.py
   Прогресс виден в Output Log (фильтр "RTD"). Это 45 тысяч экземпляров, займёт до минуты.
   Всё создаётся в папке Outliner "RoadToDawn_Gen". При повторном запуске предыдущий результат удаляется сам.
   Настройки (деревья, нав-меш, свет) в начале скрипта.

5. Проверка
   - PlayerStart (RTD_RedneckStart) стоит на каменной площадке над серпантином, камера смотрит на поселение.
   - Дорога лежит на земле по всей длине, без зависших кусков и без провалов.
   - Внешние ворота и стена кольцом, внутри вторая стена, внутри дома.
   Если дорога местами висит в воздухе или тонет, значит ландшафт импортирован не с теми настройками:
   сверьте Location и Scale из шага 2 и пришлите скриншот.
   Нав-меш: нажмите P в окне просмотра, зелёная заливка должна покрыть поселение и дорогу.

Что скрипт делает, а что нет
  Делает: блокаут из кубов, цилиндров и конусов с материалами Codex (M_RTD_*). Деревья инстансами (21 тыс.).
  Ставит ABinocularsPickup и ABearTrap у ворот, если классы найдены. PhantomTrailMarkers для бинокля не расставляет.
  Не делает: свет (в проекте есть ADayNightManager, флаг BUILD_LIGHTING = False), текстуры ландшафта по слоям, настоящие ассеты.

Генератор
  python3 rtd_generate_terrain.py <папка-вывода> [референс.png]
  Параметры в начале: R_OUT, Z_TOP (подъём дороги), VIEWPOINT, river_x(), STEP деревьев.
  После перегенерации перезалейте Landscape (Import) и запустите rtd_build_level.py ещё раз.
