# Главные правила

* План задачи находится в `.claude/tasks` и имеет имя `<N>-<task-title>.md`, где N - порядковый номер, начиная с 01, для нового плана берется следующий номер после последнего в директории
* План как правило ссылается на спецификации, которые прямо указываются пользователем или в ходе уточнения задачи
* План содержит описание задачи
* План состоит и простых шагов, желательно сопровождаемых причиной, примеры:
  * Создать код механики X для реализации требований Y, потому что...
  * Разделить модули A и B, потому что...
  * Отметить это важным для спецификации N: ...
* Шаг может быть и в том числе некой фиксацией знания, которое будет важно для дальнейшего переноса в спецификацию, знание тут - это концепция или важный момент имплементации, а не просто пересказ словами кода или изменения
* Шаг имеет маркер завершения, который служит индикатором прогресса
* Шаг по факту завершения маркируется как завершенный и сохранятеся в файл плана
