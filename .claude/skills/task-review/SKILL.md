# Главные правила

* План задачи находится в `.claude/tasks` и имеет имя `<N>-<task-title>.md`, где N - порядковый номер, начиная с 01
* План как правило ссылается на спецификации, которые прямо указываются пользователем или в ходе уточнения задачи
* План содержит описание задачи
* Шаг фиксацией знания особенно полезен для перенесения в связанные спецификации
* Изменения должены быть валидированы в соответсвии с планом и переносимыми знаниями в связанные спецификации
* Если изменения не отображают в нужной мере требования, то остановиться и выдать отчет пользователю
* Если изменения соответсвуют требованиям, то перености знания в связанные спецификации и по подтверждению пользователся удалить файл плана
