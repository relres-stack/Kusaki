# Главные правила

* Спецификация находится в `.claude/specs` и имеет имя `<N>-<spec-title>.md`, где N - порядковый номер, начиная с 01, для новой спецификации берется следующий номер после последней в директории
* Спецификацию допустимо обновлять в ходе реализации задачи
* Спецификация должна концентрироваться на основной идее функциональности больше, чем на просто пересказе имплементации
* Спецификация содержит заголовок "<спецификация> спецификация"
* Спецификация содержит короткое описание спецификации и возможное расположение кода и ассетов, к ней относящихся
* Спецификация содержит оглавление со следующими пунктами:
  1. Цель
  2. Терминология
  3. Структура кода (модуля) и/или ассетов
  4. "недочеты, допущения, "важно", открытые вопросы" - по пунктам с предшествующим "недочет:", "допущение:", "важно:", "открытый вопрос:"
  5... Остальные секции, детализирующие функционал и/или требования
* Спецификация содержит диаграммы основных процессов, если нужно
* Если секция описывает какой-то функционал или требование, начни описания с "почему это нужно: <причины>", используй детали, предоставленные пользователем, если есть.
