# Священник (Priest) — спецификация

Персонаж Священник: управление свечами как ресурсом защиты, видение вслепую и
аварийное раскидывание монстров. Код расположен в
`Source/MyCharacters/Public/PriestCharacter.h` /
`Source/MyCharacters/Private/PriestCharacter.cpp` и связанных компонентах
(`UVisionFireSourceComponent`, `UFingerFlamePeekComponent`, `UResourceStockpileComponent`).

## 1. Цель

Дать игроку персонажа, чья сила — не бесстрашие или скорость, а **создание безопасного
пространства**. Священник выстраивает вокруг себя зоны, в которые монстр не входит
безнаказанно, и ориентируется в темноте **не открывая глаза** — в отличие от Реднека,
который подглядывает с риском обнаружения. Расплата за защиту — конечность свечей:
каждое неосторожное решение уменьшает запас.

## 2. Терминология

| Термин | Значение |
|---|---|
| **Свеча** | `AHolyItem` с `ItemType == Candle`; создаёт защитные зоны пока горит |
| **Карман** | `CandleStockpile` (`UResourceStockpileComponent`); хранит до 10 свечей с индивидуальным топливом |
| **Цикл рук** | `CycleCandleHands()` — машина состояний Q: зажечь правую → левую → потушить правую → левую → по кругу |
| **Аура** | Сфера периодического оглушающего урона вокруг зажжённой свечи (`CheckAuraProximity()`) |
| **Конус защиты** | Направленная зона перед персонажем; монстр внутри зависает в состоянии Stalk (`IsLocationInProtectionCone()`) |
| **Огонёк** | `UFingerFlamePeekComponent` — 5-секундное окно видения с закрытыми глазами (F) |
| **Воспалённое зрение** | `UVisionFireSourceComponent` — полноценный пост-процесс вид от первого лица (V) |
| **Раскидывание** | `TryScatterPrayer()` — AoE толчок+стан в радиусе 500 (X) |
| **bIsPeekActive** | Флаг активного Огонька на пальцах; никогда не трогает `bIsEyesClosed` |

**Ключевые зависимости:**
- `AHolyItem` — несёт логику свечи/кадила, независимо от персонажа.
- `ABaseMonster::IsLocationProtected()` — проверяет защитную зону на стороне монстра.
- `ABaseCharacter::IsEyesClosed()` — Огонёк и Воспалённое зрение только **читают**, никогда не пишут.
- `UCandleDamageType` — общий тип урона для ауры и Раскидывания; даёт стан, не убивает.
- `UResourceStockpileComponent` — общий с Наездницей (у неё хранит масло); у Священника хранит свечи.

## 4. Недочёты, допущения, важно

**Недочёт:** Силуэтный рендер Огонька на пальцах не реализован. Флаг `bIsPeekActive`
готов, физический огонёк горит, но сами силуэты монстров/мира не рисуются. Ждёт общей
реализации Custom Depth/Stencil вместе с «Чернильными каплями» Наездницы и Mental Trail
Реднека — одна система, три потребителя.

**Недочёт:** Пересечения Воспалённого зрения (V) с другими состояниями (паника, капкан,
верховая езда) не проверялись — только скриншоты из PIE (11.11.2026).

**Недочёт:** Пересечения капкана и паники с горящими свечами в руках не тестировались.

**Недочёт:** Анимация вставания после паники (`GetUpAnimation`) — заглушка, подъём
визуально мгновенный. Общая проблема всех героев, не специфика Священника.

**Допущение:** Экономика покупки свечей не реализована (магазина нет). `CandleStockpile`
пополняется только подбором с уровня.

**Допущение:** `bAutoCrouchWithLitCandle = false` по умолчанию с 12.11.2026 — авто-присед
при зажжённой свече убран как плейсхолдер; его заменила поза рук в AnimBP. Флаг
оставлен для возврата при необходимости.

**Важно:** `ABaseCharacter::EnterPanicState()`, `Interact()`, `Tick()` сделаны `virtual`
без правки тела — вся логика Священника в override. Трогать тела базовых методов без явной
причины запрещено (`CLAUDE.md`, правило 2).

**Важно:** Свеча в руке, брошенная через ЛКМ-прицел, уничтожается немедленно — `Destroy()`
в `AHolyItem::OnItemHit()` (ветка `Candle`). Ветка `Censer` (кадило) не затронута.

**Важно:** Огонёк (F) и Воспалённое зрение (V) — **разные способности** с разными целями.
F — игровая логика состояния «вижу вслепую» (5с/5с, без риска). V — полноценный
визуальный режим от первого лица с пост-процессом. Они сосуществуют независимо.

## 5. Основная идея персонажа

Почему это нужно: Redneck действует через риск (открытые глаза/самогон), Rider — через
контроль монстра. Нужен персонаж, чья стратегия — **не выходить на открытый конфликт**,
а создавать зоны, которые монстр обходит или входит с потерями.

Священник строит защиту в пространстве: горящая свеча в руке — радиус неприкосновенности
прямо сейчас. Две свечи — два слоя. Но свечи горят, ломаются и навсегда теряются при
броске. Игрок постоянно выбирает: **держать и стоять в защите** или **бросить сейчас и
потерять её навсегда**.

Видение вслепую — его вторая опора. Там, где другие герои рискуют глазами или угадывают
по звуку, Священник получает собственный временный «радар» (Огонёк) и полноценный режим
восприятия (Воспалённое зрение) — оба без риска обнаружения.

Аварийный выход — Раскидывание молитвой: не убивает, но разбрасывает всех в стороны,
давая секунды для манёвра. Единственный его «кулак».

## 6. Механика: Святая свеча

Почему это нужно: без свечи у Священника нет отличия от базового персонажа — это его
основной инструмент, всё остальное помогает им управлять или компенсирует их потерю.

Зажжённая свеча в руке создаёт **два независимых слоя защиты**:

**Конус (направленный)** — `IsLocationInProtectionCone()`:
Монстр, попавший в конус перед персонажем, не завершает атаку и зависает у края
освещённой зоны (состояние Stalk). Защита строго направленная — монстр сбоку/сзади
не блокируется.

**Сфера ауры** — `CheckAuraProximity()`:
Любой монстр в радиусе ауры периодически получает оглушающий урон через `UCandleDamageType`
(`ApplyStun()`). Не убивает — только дезориентирует и отбрасывает.

Монстр, видящий открытые глаза игрока, продолжает преследование даже у края света;
свеча блокирует именно атаку/поимку, не обнаружение.

```
Свеча в руке
├── Конус вперёд → монстр в конусе: Stalk (не атакует)
└── Сфера ауры → монстр в радиусе: периодически оглушён
```

Монстр без здоровья (неубиваемый) реагирует аналогично — отброс, но не смерть.

## 7. Механика: Карман свечей и управление руками (Q)

Почему это нужно: без кармана игрок вынужден либо всегда держать свечи в руках (нельзя
использовать прицел нормально), либо выбрасывать лишние (потеря). Карман даёт запас и
гибкость — можно взять свечу когда нужно, убрать когда мешает.

**Карман** `CandleStockpile` (потолок 10 свечей) + параллельный `TArray<float> PocketCandleFuel`
(индивидуальное топливо каждой свечи в кармане):

- `Interact()` override: найденная свеча уходит в карман (не в руку), если есть место.
  Если полон — `Super::Interact()` (обычный подбор в руку).
- HUD: количество в слоте `Utility` (кнопка `3`).

**Цикл Q** — `CycleCandleHands()`, циклическая машина состояний:

```
Обе руки пустые
  ──Q──▶  Зажечь правую (из кармана)
  ──Q──▶  Зажечь левую (обе горят)
  ──Q──▶  Потушить правую → в карман с текущим топливом
  ──Q──▶  Потушить левую → в карман с текущим топливом
  ──Q──▶  Обе руки пустые (круг замкнут)
```

No-op при попытке зажечь с пустым карманом. No-op при попытке потушить в полный карман.

**Топливо** — частично сожжённая свеча возвращается в карман с **текущим** остатком, не
перезаряжается. При следующем зажигании догорает с того же места.

**Поза AnimBP**: флаги `bCandleInRightHand`/`bCandleInLeftHand` (`BlueprintReadOnly`)
обновляются каждый тик. AnimBP `ABP_Unarmed` блендирует позу руки (Layered Blend per Bone)
при `true`. `bAutoCrouchWithLitCandle = false` по умолчанию.

## 8. Механика: Потеря свечей

Почему это нужно: без риска потери карман превращается в бесконечный ресурс — не было бы
никакого напряжения. Потеря делает каждое решение значимым.

Три пути безвозвратной потери:

| Событие | Механизм | Результат |
|---|---|---|
| Свеча догорела в руке сама | `Tick()` на `APriestCharacter`, `FuelRemaining <= 0` | `Destroy()`, в карман не возвращается |
| Брошена через прицел (ЛКМ) | `AHolyItem::OnItemHit()`, ветка `Candle` | Стан-AoE по зоне попадания, затем `Destroy()` |
| Паника — независимый бросок 20% на каждую руку | `APriestCharacter::EnterPanicState()` override | Не повезло (20%) → `Destroy()`; повезло (80%) → тухнет, в карман с текущим топливом |

Паника гасит **обе** горящие руки — `Super::EnterPanicState()` вызывается первым,
затем очищаются руки. Шанс поломки `CandleBreakChanceOnPanic = 0.2f`, бросок **независим**
для каждой руки (могут сломаться обе, одна, ни одна).

## 9. Механика: Огонёк на пальцах (F)

Почему это нужно: Священнику нужен способ ориентироваться вслепую без риска — в отличие
от Реднека (ПКМ открывает глаза, монстр видит игрока). Огонёк даёт ограниченное по времени
«слепое зрение», не нарушая правило закрытых глаз.

**Файлы:** `UFingerFlamePeekComponent`, `APriestCharacter::FingerFlameLight`.

**Условие активации:** только если `IsEyesClosed() == true`. При открытых глазах — no-op.

**Поведение:**
```
F нажата → IsEyesClosed()?
  Нет → no-op
  Да → bIsPeekActive = true, таймер PeekDuration (5с)
         F нажата повторно → досрочная отмена → сразу кулдаун PeekCooldown (5с)
         Таймер истёк → bIsPeekActive = false → кулдаун PeekCooldown (5с)
```

Никогда не вызывает `OpenEyes()`/`CloseEyes()`/`ForceEyesOpen()`. `bIsEyesClosed`
не трогается ни при каком условии.

**Физический свет** — `APriestCharacter::FingerFlameLight` (`UPointLightComponent`,
кость `hand_r`): Intensity=600, AttenuationRadius=200, `FLinearColor(1.0, 0.45, 0.15)`.
Включается/выключается синхронно с `bIsPeekActive`.

**Силуэтный рендер** — ⏳ не реализован (см. раздел 4).

## 10. Механика: Воспалённое зрение (V)

Почему это нужно: Огонёк (F) — короткий «радар», чисто игровая логика. Воспалённое зрение —
другой режим: полноценное вИдение мира «через воспалённые веки», с атмосферой и физическим
присутствием огня на руке. Это самовыражение персонажа, а не утилита.

**Файлы:** `UVisionFireSourceComponent`, `AVisionFireSource`, `M_InflamedVision`,
`APriestCharacter::VisionFirstPersonCamera`, `VisionArmsMesh`.

**Переключение камеры** — `SetVisionFirstPersonActive(bActive, bShowRaisedArm)`:
- Активно: камера → `VisionFirstPersonCamera` (прикреплена к кости `head`); собственный
  меш скрыт от камеры (`SetOwnerNoSee()`); `VisionArmsMesh` показан (тот же скелет,
  прикреплён к камере, воспроизводит `VisionArmsAnimation`).
- Выключено: обратно к `GetFollowCamera()`.

**Рука на экране** (`VisionArmsMesh`):
- Поза фиксирована (`VisionArmsAnimation`) — рука статична относительно экрана как в
  классических шутерах от первого лица.
- Плавно поднимается при включении и опускается при выключении
  (`VisionArmRaiseAlpha`, `VisionArmRaiseSpeed = 5.0`).
- Лёгкое покачивание (`VisionArmsBobOffset`, `VisionArmBobSpeed = 0.6`).

**Огонь** — `AVisionFireSource` спавнится компонентом, крепится к кончику пальца
(сокет `middle_03_r` → fallback `hand_r`). Луч из пальца определяет направление.

**Пост-процесс** — `M_InflamedVision` (Domain Post Process, Before DOF):

```
Мир ближе ~7.5 м  → почти чёрный (DetailKeep)
Дальше            → нарастающий тёмно-коричневый туман
Поверх            → процедурный клубящийся шум (ветер, плотность — P1)
```

Параметры `P1` = (плотность тумана, масштаб шума, ветер).  
Параметры `P2` = (дальность перехода цвета, `ShapeKeep`, яркость тумана).

Монстры не выделяются специально — прячутся за геометрией как обычно (силуэты монстров
относятся к Огоньку/F, см. раздел 9).

## 11. Механика: Раскидывание молитвой (X)

Почему это нужно: Священник — персонаж защиты, не атаки. Но когда монстры окружили
вплотную, нужен аварийный выход. Раскидывание не убивает (Священник — не убийца) но
даёт секунды и пространство для манёвра без траты свечей.

**Файл:** `APriestCharacter::TryScatterPrayer()`.

**Поведение:**
```
X нажата → bIsPanicking? → no-op
           IsTimerActive(CooldownHandle)? → no-op
           SphereOverlapActors(радиус 500) → все живые ABaseMonster
             каждому: ApplyKnockback() радиально наружу (сила 1000, вверх 50)
                    + ApplyDamage(UCandleDamageType) → стан, не смерть
           → запустить таймер ScatterPrayerCooldown (20с)
```

Ресурс не тратится — `CandleStockpile` не изменяется.

Таймер кулдауна — без колбэка, только `IsTimerActive()`.

Визуал/звук: опциональный `ScatterPrayerSound` (не назначен по умолчанию); остальное —
заглушка (текст на экране). Визуальный полиш — отдельная будущая задача.

## 13. Раскладка клавиш

| Клавиша | Действие |
|---|---|
| **Q** | Цикл свечей (зажечь правую → левую → убрать правую → убрать левую → …) |
| **F** | Огонёк на пальцах (только с закрытыми глазами; 5 с / кулдаун 5 с) |
| **V** | Воспалённое зрение (тоггл) |
| **X** | Раскидывание молитвой (кулдаун 20 с) |
| **E** | Подбор свечи с пола → в карман (если есть место) |
| **ПКМ** | Прицел для броска |
| **ЛКМ** (в прицеле) | Бросить свечу — гарантированная безвозвратная потеря |
| **H** | Показать/скрыть подсказку управления (общая для всех героев) |

Общие клавиши `ABaseCharacter`: **C** (присед), **Alt** (спринт), **Space** (прыжок /
ритм-дыхание в панике), **G** (прощупывание, только в приседе).
